# GTN-Guess-The-Number-
## Что это за игра
Простейшая игра на Python, где загадывается число от 1 до 100 включительно. Игрок вводит свои догадки, а программа подсказывает, больше или меньше загаданное число, пока игрок не угадает. В конце выводится количество попыток.

Что было использовано для написания программы:
1) Библиотека random для генерации случайного числа.
2) try/except для предотвращения ошибок, если вдруг пользователь введёт не число.
3) Разделение кода на функции Check(проверка ввода) и Hints(Проверка победы и подсказки)

Чему новому я научился:
1) Обрабатывать некорректный ввод через try/except и возвращать None вместо False, чтобы не путать с числом.
2) Передавать данные в функции через аргументы, а не через глобальные переменные.
3) Считать попытки только при корректном вводе.
4) Использовать функции для упрощения понимания кода.
